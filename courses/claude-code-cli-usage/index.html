1. 설치하기

선택한 OS에 맞는 명령어만 복사해서 실행하세요.

Mac 설치

추천 경로
터미널 열기Cmd + Space → Terminal 입력 → Enter
아래 명령어 실행공식 Native Install 명령입니다.
curl -fsSL https://claude.ai/install.sh | bash
터미널 재시작명령어 인식이 안 되면 터미널을 닫았다가 다시 여세요.
Mac 설치 스크립트 초안 다운로드

Windows 설치

PowerShell 권장
PowerShell 열기시작 메뉴 → PowerShell 검색 → Windows PowerShell 실행. 프롬프트가 PS C:\로 시작해야 합니다.
아래 명령어 실행PowerShell용 공식 Native Install 명령입니다.
irm https://claude.ai/install.ps1 | iex
PowerShell 재시작claude 명령 인식이 안 되면 PowerShell을 닫았다가 다시 여세요.
Windows 설치 스크립트 초안 다운로드

Windows WSL 설치

고급 사용자용
PowerShell 관리자 권한으로 WSL 설치PC 재부팅이 필요할 수 있습니다.
wsl --install
Ubuntu에서 Claude Code 설치WSL Ubuntu 터미널 안에서 실행합니다.
curl -fsSL https://claude.ai/install.sh | bash
프로젝트는 /home 아래에 두기/mnt/c보다 /home/사용자명 경로가 안정적입니다.

2. 설치 확인

아래 명령어 결과로 버전이 보이면 설치 성공입니다.

claude --version
성공 예시: claude-code x.x.x
실패 시: 터미널/PowerShell 재시작 후 재시도

3. 첫 실행

실습 전용 폴더에서만 실행합니다. 홈 폴더/회사 Drive 전체/민감정보 폴더에서 시작하지 마세요.

mkdir -p ~/Desktop/claude-code-practice
cd ~/Desktop/claude-code-practice
claude
mkdir $HOME\Desktop\claude-code-practice
cd $HOME\Desktop\claude-code-practice
claude
mkdir -p ~/claude-code-practice
cd ~/claude-code-practice
claude

4. 첫 10분 체험

여기서 “웹/앱 Claude와 뭐가 다른지” 바로 느끼게 하는 게 목표입니다.

웹/앱 Claude

파일을 직접 올리거나 내용을 복사해서 붙여넣어야 합니다. 결과 파일도 내가 직접 만들어야 합니다.

Claude Code CLI

현재 폴더 파일을 직접 읽고, 정리한 결과를 README.md 파일로 직접 생성합니다.

memo1.md, memo2.md, todo.csv를 읽고 README.md를 만들어줘.
README에는 1) 핵심 요약 2) 담당자별 할 일 3) 다음 액션을 넣어줘.
