# 먼저 볼 파일

이 폴더는 HRD Agent Team 원본 산출물이라 파일이 많습니다. 실제 사용 순서는 아래처럼 보면 됩니다.

## 1. 교육자료로 바로 읽을 것
- `outputs/pdf/draft.html`
  - 브라우저로 열어서 전체 교육자료처럼 보면 됩니다.
- `outputs/pdf/draft.md`
  - Obsidian/Notion/문서 편집용 원본입니다.

## 2. 발표/강의안으로 쓸 것
- `outputs/slides/outline.html`
  - 슬라이드형 강의안입니다.
- `outputs/slides/outline.md`
  - PPT로 옮기기 쉬운 아웃라인입니다.

## 3. Notion에 올릴 것
- `docs/notion-draft.md`
  - Notion 페이지에 붙여넣기용입니다.

## 4. 검토할 것
- `docs/qa-report.md`
  - 배포 전 수정 권장사항입니다.

## 추천 사용법
1. 먼저 `outputs/pdf/draft.html` 열기
2. 내용 괜찮으면 `docs/notion-draft.md`를 Notion에 게시
3. 강의가 필요하면 `outputs/slides/outline.md`를 PPT로 변환/정리
4. 배포 전 `docs/qa-report.md`의 지적사항만 반영

## 현재 QA 주의사항
- “85%”, “40%” 같은 수치는 원 출처가 약하므로 삭제하거나 “많은 사용자”, “생산성 향상 사례”처럼 완화하는 것을 권장합니다.
