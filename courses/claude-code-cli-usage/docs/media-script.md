# Claude Code 완전 초보 사용법 — 영상 스크립트

**총 분량:** 약 5분 30초
**대상:** 코딩 경험 무관한 사내 임직원
**학습 목표:** Claude Code를 설치하고, Plan Mode와 슬래시 명령어를 활용해 첫 작업을 완료할 수 있다.

[화면: 타이틀 카드 — "Claude Code 완전 초보 사용법"]

"저는 개발자가 아닌데요?"라고 생각하실 수도 있어요. 괜찮습니다. Claude Code는 여러분이 자연어로 말하면 Claude가 코드를 직접 작성하고 수정해 주는 도구거든요. 오늘 이 영상 하나면 충분히 시작할 수 있습니다.

## [본론 1] 설치 — 약 1분

[화면: 터미널 창 실행 — macOS Spotlight에서 "Terminal" 검색]

먼저 설치부터 해볼게요. Claude Code는 npm으로 설치합니다. 터미널을 열고 아래 명령어를 입력해 주세요.

[화면: 터미널에 명령어 입력 — `npm install -g @anthropic-ai/claude-code`]

```
npm install -g @anthropic-ai/claude-code
```

Node.js 18 버전 이상이 필요한데요, 만약 Node.js가 없다면 nodejs.org에서 먼저 설치하시면 됩니다.

[화면: 설치 완료 메시지]

설치가 끝나면 이렇게 완료 메시지가 뜹니다. 참 쉽죠?

## [본론 2] 첫 실행 — 약 1분

[화면: 터미널에서 프로젝트 폴더로 이동 — `cd my-project`]

이제 작업할 프로젝트 폴더로 이동한 다음, `claude`라고 입력해서 실행해 봅시다.

[화면: 터미널에 `claude` 입력 → Claude Code 인터페이스 실행]

처음 실행하면 Claude Code가 프로젝트 파일들을 쭉 스캔합니다. 어떤 프레임워크를 쓰는지, 어떤 구조로 되어 있는지를 파악하는 거예요. 이 과정을 먼저 확인하고 시작하는 게 좋습니다.

[화면: 슬래시 명령어 `/init` 입력]

그 다음, `/init`이라고 입력해 보세요. 그러면 CLAUDE.md라는 파일이 자동으로 만들어지는데요,

[화면: CLAUDE.md 파일 내용 표시]

이 파일이 Claude Code에게 "이 프로젝트가 어떻게 동작하는지"를 알려주는 설명서 역할을 합니다. AI 팀원을 위한 온보딩 문서라고 생각하시면 돼요. 빌드 명령어나 코딩 규칙 같은 걸 여기에 적어두면, 매번 설명하지 않아도 됩니다.

## [본론 3] 핵심 기능 시연 — 약 2분 30초

### Plan Mode

[화면: Claude Code 인터페이스에서 Shift+Tab 두 번 입력 → "Plan Mode" 표시]

자, 이제 가장 중요한 기능을 보여드릴게요. Plan Mode입니다. `Shift+Tab`을 두 번 누르면 활성화되는데요,

[화면: Plan Mode 상태에서 프롬프트 입력]

이 상태에서 Claude에게 작업을 요청하면, 코드를 바로 수정하는 게 아니라 먼저 단계별 계획을 보여줍니다.

[화면: Claude가 계획 목록을 출력하는 장면]

"1단계에서 이 파일을 열고, 2단계에서 이 함수를 수정하겠습니다" 이런 식으로요. 계획을 확인하고 "좋아, 진행해" 하고 승인을 해야 그때서야 실제 수정이 이루어집니다. 초보자분들께 이 기능을 꼭 권장드립니다. 계획에 시간을 쏟을수록 결과물의 완성도가 높아집니다.

### 효과적인 프롬프트 작성

[화면: 프롬프트 입력 창에 나쁜 예시 텍스트 표시]

그리고 프롬프트를 잘 쓰는 것도 중요한데요. 이런 식으로 막연하게 쓰시면 안 됩니다.

> "로그인 버튼 고쳐줘"

[화면: 좋은 예시 텍스트로 전환]

대신 이렇게 구체적으로 써보세요.

> "src/components/LoginButton.tsx 파일에서 로그인 버튼 클릭 시 API가 500 에러를 반환할 때 에러 메시지가 표시되지 않는 버그를 수정해줘. React 18, TypeScript, axios를 사용 중이야."

[화면: 두 프롬프트 나란히 비교하는 화면]

파일명, 기술 스택, 그리고 구체적인 상황을 함께 주면 Claude가 훨씬 정확하게 작업합니다. 신규 사용자의 85%가 모호한 프롬프트 때문에 어려움을 겪는다고 하니, 처음부터 습관을 잘 들여두는 게 중요합니다.

### 컨텍스트 관리

[화면: `/clear` 명령어 입력]

마지막으로 컨텍스트 관리를 말씀드릴게요. Claude와 대화를 오래 하다 보면 대화 기록이 쌓여서 성능이 떨어질 수 있어요. 새로운 작업을 시작할 때마다 `/clear`를 입력해서 기록을 초기화해 주세요.

[화면: `/compact` 명령어 입력]

30분 이상 긴 세션에서는 `/compact`를 쓰면 대화 내용을 요약해줘서 토큰을 절약할 수 있습니다. 파워 유저들은 이 방법으로 생산성을 최대 40%까지 높인다고 하더라고요.

[화면: 슬래시 명령어 전체 목록 표 — 자막 형태로]

참고로 자주 쓰는 명령어를 정리해 드리면, `/help`로 전체 명령어를 확인하고, `/doctor`로 설치 상태를 진단할 수 있습니다. `/memory`는 CLAUDE.md를 바로 편집할 때 씁니다.
