### media-script.md

**학습목표 명확성: 충족**
- 스크립트 최상단(헤더 영역)에 학습 목표를 1문장으로 명시함.
- 단, 슬라이드/PDF처럼 복수 항목으로 상세 기술되지 않고 단일 문장으로 요약됨. 영상 포맷의 특성상 허용 가능한 수준.

**정확도 검토**
- 주요 수치, 명령어, 기능 설명 모두 research.md와 일치.
- "신규 사용자의 85%가 모호한 프롬프트 때문에 어려움을 겪는다" — 다른 산출물과 동일. 원 출처 URL 미연결.
- "생산성을 최대 40%까지 높인다" — 다른 산출물과 동일. 원 출처 URL 미연결.
- 참고 링크(영상 설명란용) 섹션에 5개 URL 포함됨.

**온보딩 적합성: 충족**
- 총 분량: "약 5분 30초" 명시 — 30분 기준 대비 충분히 여유 있음.
- 대상: "코딩 경험 무관한 사내 임직원" 명시.
- 화면 전환 지시([화면: ...]) 포함으로 촬영 가이드 완비.
- 구어체로 작성되어 비개발자가 시청하기에 적합.

**기타 지적사항**
- 스크립트가 영상 제작 지침(화면 전환, 분량)을 포함하고 있어 제작자 친화적이나, 나레이터가 읽을 대사와 연출 지시가 혼재되어 있음. 실제 촬영 시 대사 전용 버전 분리를 권장.
- 아웃트로에서 "공식 문서의 베스트 프랙티스 가이드도 꼭 한 번 읽어보시길 권장드립니다"라고 언급하나 영상 내에서 링크 화면이 지시되지 않음. 영상 설명란 링크와 연결하는 자막 추가 권장.

- "신규 사용자의 85%", "생산성 최대 40% 향상" 수치 — 동일하게 원 출처 URL 없이 간접 출처만 표기됨.

**온보딩 적합성: 충족**

**기타 지적사항**

## 개선 권고사항

### 긴급 수정 (배포 전 필수)

1. **피드백 채널명 불일치 수정**
   - `notion-draft.md`: `#hrd-education` → `#onboarding` 으로 통일
   - 또는 전 산출물에서 채널명을 단일 채널로 합의 후 일괄 수정

2. **`/config` 명령어 목록 통일**
   - `pdf/draft.md`와 `notion-draft.md`의 슬래시 명령어 표에 `/config` 누락
   - research.md 및 notebooklm/source.md의 전체 목록에는 포함되어 있으므로, 의도적 제외라면 근거 명시 / 누락이라면 추가 필요

### 권장 보완 (배포 후 다음 버전에서 반영)

3. **수치 인용 출처 명확화**
   - "신규 사용자의 85%" — 원 출처 URL 연결 권장 (현재 research.md에도 URL 미연결)
   - "생산성 최대 40% 향상" — 동일. Builder.io 또는 관련 아티클 URL 각주 추가 권장

4. **`/context` 명령어 존재 여부 검증**
   - slides/outline.md와 pdf/draft.md에 포함되어 있으나 research.md의 슬래시 명령어 공식 목록에는 없고 기능 설명 텍스트에만 언급됨
   - 공식 문서에서 실제 명령어 여부 확인 후, 없으면 "컨텍스트 사용량은 자동으로 표시됨" 등으로 표현 수정 권장

5. **media-script.md 대사/연출 지시 분리**
   - 나레이터 대사와 화면 연출 지시를 별도 열 또는 색상으로 구분한 프로덕션용 버전 제작 권장

6. **소요 시간 안내 일관성**
   - slides 표지(30분)와 pdf/notion(20분) 차이가 명확히 다른 산출물을 가리키는 것임을 각 자료에서 분명히 안내하면 수강자 혼선 방지 가능
