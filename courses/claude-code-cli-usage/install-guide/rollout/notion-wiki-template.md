# Notion / Wiki 랜딩 페이지 템플릿

## Claude Code CLI 온보딩

Claude Code CLI는 웹/앱 Claude와 달리 로컬 폴더의 파일을 읽고, 결과 파일을 만들고, 작업을 검토할 수 있는 CLI 도구입니다.

### 먼저 할 일

1. 최신 온보딩 zip 다운로드: `[Drive 링크]`
2. 압축 해제 후 `START_HERE.md` 열기
3. 내 OS에 맞는 설치 가이드 진행
4. 설치 후 `sample-files/`로 첫 10분 체험

### OS별 안내

| OS/상황 | 안내 |
|---|---|
| macOS | Part A macOS 설치 가이드 |
| Windows 일반 사용자 | Part B Windows Native 설치 가이드 |
| Windows PowerShell/CMD 혼동 | Part B의 PowerShell/CMD 구분 섹션 |
| Windows 개발자/고급 사용자 | Native 먼저, 필요 시 Part C WSL |
| Linux | Part D Linux 설치 가이드 |

### 문제해결

- FAQ: `FAQ-문제해결-지원동선.md`
- 지원 채널: `#claude-code-onboarding-help`
- 요청 시 첨부: OS, 실행 명령어, 오류 캡처, `claude --version`, `claude doctor`

### 버전 정보

- 문서 버전: vX.X
- 마지막 업데이트: YYYY-MM-DD
- 담당: HRD/IT
