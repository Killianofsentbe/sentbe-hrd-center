# Slack 공지 템플릿

안녕하세요. Claude Code CLI 사내 온보딩 파일럿을 시작합니다.

Claude Code CLI는 웹/앱 Claude와 달리 **내 컴퓨터 폴더의 파일을 직접 읽고, 결과 파일을 만들고, 작업을 검토**할 수 있는 도구입니다.

## 참여 방법

1. Drive 폴더에서 `Claude-Code-CLI-Onboarding-vX.X.zip` 다운로드
2. 압축 해제 후 `START_HERE.md` 먼저 열기
3. 내 OS에 맞는 설치 가이드 진행
4. 설치 완료 후 `sample-files/`로 첫 10분 체험 진행

## OS별 바로가기

- Mac: `Claude-Code-CLI-OS별-설치-가이드.md` → Part A
- Windows: `Claude-Code-CLI-OS별-설치-가이드.md` → Part B Native Windows
- Windows 고급/개발자: Part B 먼저, 필요 시 Part C WSL

## 막혔을 때

설치가 막히는 것은 정상적인 온보딩 이슈입니다. 아래 템플릿으로 `#claude-code-onboarding-help`에 올려주세요.

```text
[Claude Code CLI 설치 지원 요청]
1. OS:
2. 실행한 터미널: PowerShell / CMD / macOS Terminal / WSL Ubuntu
3. 실행한 명령어:
4. 오류 메시지 또는 캡처:
5. claude --version 결과:
6. claude doctor 결과:
7. 회사 VPN/프록시 사용 여부:
```

파일럿 기간: YYYY-MM-DD ~ YYYY-MM-DD
지원 가능 시간: HH:MM ~ HH:MM
담당: HRD/IT 담당자
